# Bot Meets Shortcut: How Can LLMs Aid in Handling Unknown Invariance OOD Scenarios?

Research project website: https://worfsmile.github.io/BotMeetsShortcut/

## Preview

Run `python -m http.server 8000` in this directory, then visit http://localhost:8000.

## Publish

GitHub Pages publishes the `main` branch, repository root. No build dependencies are required.

## Materials

The Paper button links to the author-provided Google Drive PDF. Figures and supplementary media are reproduced from the supplied research materials. The paper PDFs are not duplicated in this repository.

Edit `index.html`, `styles.css`, and `script.js` to update the site. Preserve relative asset paths for GitHub project Pages.
